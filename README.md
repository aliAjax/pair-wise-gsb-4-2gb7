# License Lens

纯前端开源依赖许可证兼容性分析工具。打开 `index.html`，可粘贴或上传依赖清单，识别常见许可证、查看依据、筛选风险、手动添加条目并导出 Markdown 报告。

## 例外审批（豁免）

- 每条「需复核 / 高风险」结论都可申请豁免，记录**分发方式、审批人、依据链接、到期日**。
- 同一依赖 + 同一分发方式只允许一份生效豁免（申请弹窗会禁用已有生效豁免的分发方式）；再次批准需走**续期**：旧版本标记为「已被新版本取代」并保留，生成 v+1 新版本，完整版本链可在「查看依据」中追溯，也可撤销误批的豁免。
- **GPL / Proprietary 不得凭普通豁免降为通过**：这两类许可证必须勾选「已经法务审批」并填写审批人，否则一直挂「待法务审批」。
- 豁免数据保存在浏览器 `localStorage`，刷新后裁决、豁免版本与到期状态保持一致（裁决始终由「当前分析结果 + 豁免记录 + 今天日期」推导，无冗余缓存）。

## 到期回收与风险升级

- 豁免到期当天结束后自动失效，依赖自动回到待复核；回到页面或跨天时状态自动重算。
- 重新分析后若风险等级升级（兼容通过 → 需复核 → 高风险，豁免带批准时快照），相关豁免自动失效并回到待复核，需重新申请或续期。
- 「开始分析」会列出因风险升级而自动失效的豁免；导出的 Markdown 报告含当前裁决与全部豁免版本记录。
