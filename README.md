# License Lens

纯前端开源依赖许可证兼容性分析工具。打开 `index.html`，可粘贴或上传依赖清单，识别常见许可证、查看依据、筛选风险、手动添加条目并导出 Markdown 报告。

## 豁免审批与到期回收

- 每项「需复核 / 高风险」结论都可按分发方式申请豁免，记录分发方式、审批人、依据链接、到期日与法务审批信息。
- 结论按当前「分发方式」切换实时裁决：生效豁免 > 到期/升级回退 > 原始分析结论。
- 同一依赖同一分发方式仅允许一份生效豁免；续期自动生成新版本（v1、v2…），旧版本完整保留在豁免记录中。
- GPL / Proprietary 许可证不得凭普通豁免降为通过，必须勾选法务审批并填写法务审批人。
- 豁免到期、或重新分析后风险等级上升（如 需复核 → 高风险）时，该依赖自动回到「需复核」，续期后方可再次豁免。
- 依赖清单、豁免版本与到期状态保存在 localStorage，刷新或重开页面后裁决保持一致。
- 导出的 Markdown 报告包含分析结论、当前裁决及全部豁免记录。
